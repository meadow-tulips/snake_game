### Snake Game

Built using c++ (raylib library).

Uses the raylibquickstarter template.


Take a look at the CMakeLists.txt file to see the expected folder setting for external Lib.



# Folder Structure

- build/external/raylib-master  // This is where your github repo should reside
- include      // Contains header files
    - Entity.h
    - Food.h
    - Snake.hpp
    - resource_dir.h (coming from starter template)
- src
    - Entity.cpp
    - Food.cpp
    - main.cpp
    - Snake.cpp
- CMakeLists.txt
- gitignore
- ReadMe
